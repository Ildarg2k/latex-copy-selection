LaTeX Copy Selection v1.3.4

Подробная инструкция на русском (русифицированный Chrome):
  откройте файл  ИНСТРУКЦИЯ.txt  в этой же папке.

Кратко / Quick install:
1. chrome://extensions
2. Включите «Режим разработчика» / Developer mode
3. «Загрузить распакованное расширение» / Load unpacked
4. Выберите ЭТУ папку (где лежит manifest.json)

Использование: выделить текст с формулами → значок расширения → Copy
(или Ctrl+C) → вставить.

Версия пакета: 1.3.4 (должна совпадать с chrome://extensions).
