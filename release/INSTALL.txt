LaTeX Copy Selection v1.3.4

Full guide: https://github.com/Ildarg2k/latex-copy-selection
Русский текст: https://github.com/Ildarg2k/latex-copy-selection/blob/main/README.ru.md

Install:
1. chrome://extensions
2. Turn on Developer mode
3. Load unpacked
4. Select THIS folder (the one that contains manifest.json)

Use: select text with formulas, then the extension icon → Copy
(or Ctrl+C) → paste.

Package version: 1.3.4 (must match chrome://extensions).
