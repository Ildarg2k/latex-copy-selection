================================================================================
  LaTeX Copy Selection — как установить и пользоваться
================================================================================

Версия пакета: смотрите manifest.json (сейчас 1.3.4).

Расширение для Chrome. Вы выделяете текст на странице, где формулы уже
нарисованы (KaTeX, MathJax, Wikipedia, arXiv HTML, Stepik, Gemini и похожие
сайты), и копируете его. В буфер попадает обычный текст, а формулы — как
LaTeX: $...$ и $$...$$ (или \(...\) / \[...\], если так выбрано в настройках).

Дальше вставляете в Obsidian, Markdown, Overleaf, Telegram или другой
редактор, который понимает такие формулы.

Это не кнопка «скопировать одну формулу по наведению». Копируется текущее
выделение целиком: абзац, несколько формул, подписи.


--------------------------------------------------------------------------------
1. ЧТО ЗАГРУЖАТЬ В CHROME
--------------------------------------------------------------------------------

Нужна именно ЭТА папка (release), а не родительская папка проекта.
В ней должны лежать:

  • manifest.json
  • content.js, sw.js
  • options.html, options.js, options.css
  • icons\
  • LICENSE
  • INSTALL.txt
  • ИНСТРУКЦИЯ.txt  (этот файл)

Если скачали zip с GitHub Release — распакуйте его. Загружать нужно папку,
внутри которой сразу лежит manifest.json.


--------------------------------------------------------------------------------
2. УСТАНОВКА
--------------------------------------------------------------------------------

  1) Откройте chrome://extensions
     (или Меню Chrome → Расширения → Управление расширениями).

  2) Включите «Режим разработчика» (переключатель справа вверху).

  3) Нажмите «Загрузить распакованное расширение».

  4) Укажите папку, где лежит manifest.json.

  5) В списке появится «LaTeX Copy Selection». Переключатель должен быть
     включён.

Значок можно закрепить: кнопка-пазл на панели Chrome → булавка у
«LaTeX Copy Selection».


--------------------------------------------------------------------------------
3. КАК КОПИРОВАТЬ
--------------------------------------------------------------------------------

  1) Откройте страницу с формулами.

  2) Выделите фрагмент (можно целый абзац).

  3) Скопируйте:
     • значок расширения → кнопка Copy selection, или
     • Ctrl+C / Cmd+C, если включено Allow Ctrl+C.

  4) Вставьте куда нужно (Ctrl+V). Формулы станут $...$ или $$...$$.

Кнопка Copy selection работает всегда и после успеха закрывает окошко.
Если Allow Ctrl+C выключено, клавиатурное копирование остаётся обычным
поведением Chrome, а кнопка по-прежнему кладёт выделение в буфер сама.

Если в выделении нет распознанной формулы, в буфер всё равно попадает
очищенный текст выделения — и с кнопки, и с Ctrl+C (когда он включён).
Так сайты не дописывают в конец копирования свою подпись.


--------------------------------------------------------------------------------
4. ОКНО РАСШИРЕНИЯ
--------------------------------------------------------------------------------

Клик по значку открывает окошко. Подписи на английском, как в программе.

  Copy selection
      Скопировать текущее выделение.

  Allow copy on this site
      Разрешить выделение и правый клик на этом сайте, если страница их
      блокирует. Также можно скопировать текст из заблокированных полей
      (например ответы в тесте Stepik). Пока включено, на значке зелёная
      метка ON. Не работает в Canvas и Google Документах.

  Allow Ctrl+C
      Включено: Ctrl+C / Cmd+C кладёт выделение в буфер так же, как кнопка.
      Выключено: Ctrl+C — обычное копирование Chrome.

  Clipboard target
      Markdown / LaTeX (по умолчанию)
          Текст с формулами $...$ / $$...$$. Для Obsidian, Overleaf, Telegram.
          Картинки из выделения в HTML-части буфера сохраняются.
      Rich / Office
          Формулы в LaTeX не переписываются. В буфер уходит исходное
          выделение, как для LibreOffice или Word, без вставок самого сайта.

  Delimiter style
      $...$ / $$...$$   или   \(...\) / \[...\]

Настройки сохраняются сразу (надпись Saved).


--------------------------------------------------------------------------------
5. ГДЕ ФОРМУЛЫ РАСПОЗНАЮТСЯ
--------------------------------------------------------------------------------

Страница должна хранить исходный TeX в HTML, а не только картинку.

  • KaTeX
  • MathJax 2 и 3
  • MathML, в том числе Wikipedia
  • HTML arXiv / LaTeXML
  • Gemini (формулы с data-xpm-latex)
  • атрибуты data-math, data-latex, data-tex, data-formula, data-equation

Из скопированного TeX убираются метки \tag{...}. Тонкие пробелы KaTeX
(\, \: \;) по возможности восстанавливаются.


--------------------------------------------------------------------------------
6. ЧЕГО РАСШИРЕНИЕ НЕ ДЕЛАЕТ
--------------------------------------------------------------------------------

  • Notion и Google Документы — уравнения там в своём формате.
  • PDF и формулы только картинкой, без TeX в коде страницы.
  • Копирование из самого приложения Telegram. Копировать нужно со страницы
    в Chrome, затем вставлять в Telegram. Клиент должен уметь формулы
    в этом чате.
  • Firefox этой сборкой не ставится. Нужен Chrome (или другой браузер
    с расширениями Chrome Manifest V3).

LibreOffice / Word
  Обычная вставка часто берёт простой текст. В режиме Markdown / LaTeX
  этот текст как раз $...$, и Writer не превратит его в свою формулу.
  Если нужен вид «как на сайте» — Clipboard target → Rich / Office.
  Если нужен именно код LaTeX — оставьте Markdown / LaTeX.


--------------------------------------------------------------------------------
7. ОБНОВЛЕНИЕ И УДАЛЕНИЕ
--------------------------------------------------------------------------------

Новая версия папки:
  chrome://extensions → на карточке расширения кнопка обновления
  (в режиме разработчика), либо удалите старое и снова загрузите папку.

Удаление:
  chrome://extensions → Удалить у «LaTeX Copy Selection».


--------------------------------------------------------------------------------
8. ЕСЛИ НЕ СРАБОТАЛО
--------------------------------------------------------------------------------

  • Расширение включено на chrome://extensions?
  • Загружена папка, внутри которой лежит manifest.json?
  • Allow Ctrl+C выключено? Тогда пользуйтесь кнопкой Copy selection.
  • Страница не отдаёт копировать? Включите Allow copy on this site
    и обновите вкладку.
  • На сайте формулы только картинками — LaTeX взять неоткуда.
  • После смены настроек обновите вкладку и скопируйте снова.
  • На карточке расширения на chrome://extensions нет ошибок?


--------------------------------------------------------------------------------
9. КОНФИДЕНЦИАЛЬНОСТЬ
--------------------------------------------------------------------------------

  • Нет аккаунта, аналитики, рекламы и отправки текста на сервер автора.
  • Логика расширения не скачивается из интернета.
  • В хранилище Chrome лежат только настройки: Allow Ctrl+C, режим буфера,
    вид скобок $ или \( и список сайтов, где включён Allow copy.
  • Если в Chrome включена синхронизация, эти настройки синхронизирует
    сам Chrome. Расширение их никуда отдельно не отправляет.
  • Скрипт на странице нужен, чтобы обработать ваше копирование и, если
    вы включили Allow copy, снять блокировку выделения на этом сайте.
